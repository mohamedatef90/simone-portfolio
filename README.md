# Simone Portfolio

A static, single-page personal portfolio template (a sample designer profile) built with HTML and CSS. It has no JavaScript and no build step.

## Sections of `index.html`

Home, About, Services, Resume, Portfolio, Clients (testimonials), and Contact, with a navigation header and a footer. The content is placeholder sample text and images.

## Tech

- HTML and CSS: `css/style.css`, with responsive rules in `css/media-quary.css`
- Font Awesome (`css/all.min.css`, `webfonts/`)
- Poppins from Google Fonts

## Running

Open `index.html` in a browser. Google Fonts need an internet connection; everything else is local.

## Project structure

```
index.html            The page
css/                  style.css, media-quary.css, and Font Awesome styles
webfonts/             Font Awesome fonts
img/                  Images
```
